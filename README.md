# Inventario AIPSA

Prototipo (borrador) del sistema de inventario de AIPSA.

- `aipsa-inventario-poc_BORRADOR.html`: un solo archivo con HTML, CSS y JavaScript, sin dependencias ni build. Se abre directamente en el navegador.
- Los datos son de ejemplo y viven en memoria: no hay backend ni persistencia, todo se pierde al recargar.

Pantallas: Materia prima, Materiales, Kits, Depósitos permanentes, Depósitos transitorios y Compras.
